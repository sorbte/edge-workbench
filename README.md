# Microsoft Edge 持久化浏览器工作台

这是一个使用 **Playwright + Tkinter** 编写的可视化浏览器控制程序。它直接驱动本机安装的 Microsoft Edge，不会改动你日常使用的 Edge 配置，而是把模拟浏览产生的内容保存在项目内的独立目录：

- `edge_profile/`：Edge 用户资料目录，持久保存 Cookies、LocalStorage、Session Storage、IndexedDB、Service Worker、HTTP 磁盘缓存、历史记录、偏好设置等。
- `downloads/`：浏览器下载目录。
- `runtime/operations.jsonl`：页面导航与模拟操作日志。
- `runtime/state_snapshots/`：手动保存的状态摘要快照（只记录 Cookie 元数据，不记录 Cookie 值）。

## 运行

双击 `run.bat`，或者执行：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 edge_workbench.py --autostart
```

程序启动后会自动打开 Edge 和 `https://cn.bing.com/`。

## 界面设计

- 无 Windows 原生标题栏，使用自定义无边框窗口
- 自定义拖动标题栏、最小化、最大化 / 还原、关闭按钮
- 右下角拖动缩放
- Codex 风格布局：标题栏与侧栏同为米灰色无缝衔接，内容区为整体浮起的白色圆角卡片（左侧与顶部带渐变软阴影）
- 侧边导航：纯导航列表，导航项由「已安装插件页面 + 核心页面」组成（默认：学习通助手、微软积分助手、总览、运行日志），选中项为贴左全宽白色高亮条；底部显示快捷键提示
- 功能插件化：功能页以插件形式放在 `plugins/` 目录，安装（放入目录）即出现在左侧菜单，禁用/卸载后自动消失；详见下方「插件系统」
- 默认进入第一个插件页；Alt+1…N 按侧栏顺序切换页面
- 一键自动运行 = 完整自动化流程：启动 Edge（如未运行）→ 获取基本数据 → 搜索任务 → 触发每日任务 → 最终数据同步；入口在积分助手页页头最左侧的「▶ 启动」按钮，运行中按钮禁用，可在积分助手页取消任务
- 隐藏模式：总览页标题栏「显示器」图标按钮开启后（按钮变为黑色激活态，悬停显示说明），浏览器以无头方式在后台运行，自动化照常执行；切换需重启浏览器生效（可用标题栏「重启浏览器」图标一键应用），注意事项：无头浏览器更易被网站反自动化策略识别，Rewards 积分存在不计入的风险
- 防重复点击：所有长耗时操作的按钮在执行期间自动禁用，worker 命令完成后自动恢复；任务运行时「开始」按钮禁用、对应「取消任务」按钮才可用；一键自动化运行期间手动任务按钮整体联动禁用
- 总览页布局：命令条式地址栏（等宽字体 + 回车执行）+「打开页面」+「必应搜索」+ 新建标签页图标；标题「运行总览」行右侧为一组图标按钮——启动 ▶ / 重启 ⟳ / 隐藏切换 ⌷ / 停止 ■（红色，均为 Segoe MDL2 图标，悬停显示中文名称）；「TELEMETRY / 运行指标」行右侧为刷新 ↻ / 快照 / 清理缓存 / 资料目录四枚图标；底部等宽路径提示行；原 ACTIONS 卡片取消
- 必应搜索：总览页输入框的内容会打开 `cn.bing.com` 后逐字输入搜索框并回车；输入框为空时仅打开必应首页
- 任务保护：搜索任务 / 一键自动化 / 模拟真实浏览 / 获取数据等运行期间，「清理缓存」与「清理 Rewards 缓存」会被拒绝并写入日志提示，不会中断正在运行的任务；「停止浏览器」与「重启浏览器」是显式的中断入口（重启会先取消任务、再按当前窗口模式启动）
- 清理缓存完成或停止浏览器后，日志会提示可点击「启动浏览器」继续；隐藏/显示切换在浏览器运行中时会提示用「重启浏览器」立即生效
- 微软积分助手页（插件）：未登录 / 无法识别数据时显示居中空状态页（原因说明 + 「刷新全部数据」引导按钮），登录并获取成功后切换到数据卡片；页头标题行右侧为整页唯一一组图标按钮（刷新全部数据 ↻ / 清理 Rewards 缓存 🗑 / 打开数据 JSON / 测试点击，悬停显示中文名）；下方依次为「ACCOUNT 账户与数据摘要」卡（账户信息 + Rewards 数据摘要，两页原有内容已去重合并）、搜索任务 / 每日任务两张独立进度卡（各自的进度条、开始与取消按钮）、「SEARCH RULES 积分规则」网格
- 学习通助手页（插件）：打开页面时只读取本机缓存，不会自动启动独立 Edge；只有用户点击「同步全部数据」后才启动并进入学习通。展示用户名、用户 ID、头像标识以及全部学历课程（在读 / 历史），并显示课程类型、学期、任务点、测验和整体进度；首次使用会跳转到学习通登录页，请在插件独立 Edge 中使用“学习通”App 扫描二维码登录；用户与课程缓存写入 `runtime/plugins/chaoxing_assistant/profile.json` 和 `courses.json`，Cookie/LocalStorage/SessionStorage 快照写入 `auth_state.json`。
- 学习通助手「开始学习」：只有用户点击后才执行；它会从课程目录查找未完成章节，按视频、PPT/PDF、电子书分别完成，并在每个任务点后重新检查。连续 3 次仍有任务点未完成时，点击下一节并在界面提示“课程异常”；处理报告写入 `runtime/plugins/chaoxing_assistant/study_report.json`。
- 合并去重说明：原「Rewards」页与「账户与规则」页的空状态、获取数据入口、清理缓存入口、可用积分（与账户积分重复）、积分规则文本摘要（与规则网格重复）均已合并为一份
- 搜索任务与每日任务的事件流相互独立（flow 标记），互不覆盖对方进度
- 小字号统一调大（等宽 10pt 起、正文 11pt 起），日志终端面板 10pt
- 运行日志页：深色终端面板（`▌ operations` 头行、弱色时间戳、按级别着色的日志）
- 快捷键：Alt+1…4 切换页面
- 整体主按钮为石墨黑，避免高饱和蓝色
- Edge 路径自动检测：依次检查 Program Files、Program Files (x86) 和 LocalAppData，并使用 Playwright channel=msedge 驱动本机 Edge

## 插件系统

功能页面以插件形式与宿主解耦：宿主只保留总览、运行日志等核心页，其余功能装进 `plugins/` 下的独立目录。

- 目录结构：每个插件一个文件夹，含 `manifest.json`（清单）与入口模块（默认 `plugin.py`）

  ```json
  {
    "id": "microsoft_points_assistant",
    "name": "微软积分助手",
    "version": "1.0.0",
    "description": "Microsoft Rewards 积分数据、账户规则与任务中心",
    "entry": "plugin.py",
    "plugin_class": "MicrosoftPointsAssistantPlugin"
  }
  ```

- 安装即显示：把插件文件夹放进 `plugins/` 后启动程序，页面会自动注册到左侧菜单顶部；删除文件夹或禁用后消失
- 热更新（无需重启）：插件管理页点「扫描新插件」即可装载新放入 `plugins/` 的插件；开关切换即时挂载/卸载页面；关闭再打开开关会重新读取插件代码（改完插件代码即时生效）；文件夹被删除后再扫描会自动卸载
- 插件管理界面：核心页「插件管理」（侧栏最后一项）列出全部已安装插件（名称、id、版本、描述、加载状态），每项一个启用/禁用开关，页头提供扫描新插件 / 重启程序 / 打开插件目录三个图标
- 任务保护：插件的自动化任务运行中，该插件不能被停用（提示后自动弹回开关）
- 插件加载失败（清单损坏、入口缺失等）会在管理页以红色标注原因；`plugins/` 为空时显示安装指引
- 启用 / 禁用：在 `runtime/plugins.json` 写入 `{"disabled": ["插件id"]}`（文件不存在时全部启用）
- 插件类继承宿主的 `WorkbenchPlugin` 基类：实现 `build_pages(parent)` 返回页面（页键、侧栏标题、框架），通过 `handle_event(event)` 接收 worker 事件流（rewards_data / rewards_account / account_info_status / search_task_status / auto_status），并可复用宿主的卡片、按钮、图标按钮、日志等 UI 套件
- 需要独立浏览器的插件可在 `manifest.json` 中增加 `worker_entry`；宿主会将插件命令交给该 worker 注册，学习通助手使用 `chaoxing_refresh` / `chaoxing_open_space` / `chaoxing_open_course` / `chaoxing_study` 四条命令。
- 单个插件加载或运行失败只写入运行日志，不影响宿主启动和其他插件

## 可视化功能

- 启动 / 停止 / 重启 Microsoft Edge（总览页标题行图标）
- 打开任意网址，或使用「必应搜索」把输入框内容输入 cn.bing.com 搜索
- 一键模拟真实用户：移动鼠标、点击搜索框、逐字输入、回车、随机滚动与停留（仍用于一键自动化流程）
- 新建标签页（总览页命令条 + 图标）
- 查看用户数据、HTTP 缓存、站点数据、Cookies、历史记录等实时统计
- 保存当前页面与存储状态快照
- **获取 Microsoft Rewards 基本数据**：今日积分、账户积分、当日积分进度、日常任务进度、已完成 / 未完成任务、Edge 浏览时长
- **安全清理缓存**：删除可重建的 HTTP 缓存、Code Cache、GPU/Shader 缓存、BrowserMetrics 和诊断日志，保留登录、Cookies、History、LocalStorage、IndexedDB 与 Service Worker
- **清理 Rewards 缓存**（积分助手页页头的垃圾桶图标）：删除 `runtime/rewards_data.json` 与 `runtime/rewards_account.json`，并把积分助手页重置为空状态；获取数据期间按钮自动禁用
- **获取账户与积分规则**：读取用户名、会员等级、可用积分、可领取积分、连续打卡、升级剩余活动，并从 `/about` 解析各等级积分规则
- 积分规则包含每次搜索积分、各等级每日搜索上限、每月等级奖励、默认搜索奖励、Bing Star 上限、Store / Xbox 倍率和兑换折扣
- 搜索任务会动态使用规则中的“每次搜索积分”和“当前等级每日搜索上限”，不再完全依赖固定常量；结果保存到 `runtime/rewards_account.json`
- Rewards 任务解析会排除无积分选项，只保留带积分任务；数据保存到 `runtime/rewards_data.json`
- **测试点击**：优先点击 Rewards 的“今日积分 / 积分明细”按钮打开抽屉，找不到时点击 Bing 搜索框，不会自动提交任务
- **搜索任务**：根据“必应搜索”积分进度推算还需搜索的次数，从今日头条随机抽取“所需数量 + 5 条”新闻标题进行 Bing 搜索
- 搜索间隔在 18～42 秒之间随机，避免过快；连续 3 次积分未上涨时进入 15 分钟冷却，冷却后仍失败则停止并校准
- **开始每日任务**：扫描“每日活动”和“日常任务”，仅点击“未完成”项，已完成的自动跳过；点击后刷新并重新扫描，最多触发 30 项，支持取消
- 每触发 5 项同步校准一次；结束后统一读取 Rewards 数据，点击记录写入 `runtime/search_task.jsonl`
- 每 10 次搜索进入 Rewards 详细页同步校准一次，搜索结束后再做最终同步；搜索计划与结果写入 `runtime/search_task.jsonl`，新闻缓存写入 `runtime/news_cache.json`
- 打开资料目录或查看 JSONL 操作日志

## 持久化说明

Edge 资料由 Playwright 的 `launch_persistent_context(user_data_dir=...)` 管理。关闭程序后再次启动会继续使用同一份资料，因此登录状态、Cookie、站点缓存和历史记录都会保留。

注意：`edge_profile/` 属于敏感数据目录，不要提交到 Git，也不要随意分享。
